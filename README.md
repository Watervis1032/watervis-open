# watervis-open — pouch.watervis.co.kr

(처음에는 파우치 공장 오픈식 초대장용으로 만든 저장소였고, 지금은 제품 소개가 주된 쓰임이다.)

## 정해 둔 것

- **구매하기**: 한국어 페이지의 «구매하기» 버튼은 모두 `https://watervis.co.kr/order/`(지인 주문, 입장 코드 화면이 먼저 나옴)로 간다. «주문 조회»는 `…/order/#track`로 간다. 입장 코드가 없는 분은 033-672-1032로 문의하도록 안내한다.
- **카페24(shop.watervis.co.kr)를 연 뒤**: «구매하기»를 shop.watervis.co.kr로 바꾼다. 지인 주문(/order)은 메뉴에서 빼고 링크로만 보낸다. 이때 이 저장소와 watervis-company를 **둘 다** 고친다.
- **영어·중국어** 페이지는 해외 판매를 정하기 전까지 «문의»만 둔다. 주문 화면이 한국어뿐이기 때문이다.
- **이메일**은 모든 페이지에서 `admin@watervis.co.kr` 하나만 쓴다. info@, wa1032@naver.com은 쓰지 않는다.
- **전화**: 033-672-1032 / +82-33-672-1032
- **주소**: 강원특별자치도 양양군 현남면 원포1길 53

## 올리는 법 · 확인

- 파일은 GitHub 웹에서 올린다(Add file › Upload files, 또는 파일 연필 아이콘으로 수정).
